# Preuve e2e — Agent Aetherix × Sandbox Apaleo (démo candidature)

> Capturé le **2026-06-11**, stack dockerisé local (backend FastAPI + Postgres/pgvector),
> sur données **réelles** de la sandbox Apaleo (property `PAR`). Réponse brute :
> [`predict_response_2026-03-13.json`](./predict_response_2026-03-13.json).

## Ce que la démo prouve

Chaîne agentique complète, productisée, exposée via un **endpoint MCP authentifié** :

```
Apaleo sandbox (réservations + capacité réelles)
   → Prophet (forecast entraîné, is_mock=false)
   → Claude (reasoning + explainability, claude_used=true)
   → StaffingService (recommandation + deltas)
   → persistance Postgres (recommendation_cache)
```

## Requête (HTTP, bearer MCP scope `predict`)

`POST /api/v1/predictions/predict`

```json
{
  "hotel_id": "tenant_sandbox",
  "target_date": "2026-03-13",
  "service_type": "dinner",
  "context": {
    "occupancy": 0.62,
    "weather": { "condition": "Clear, 18C" },
    "events": [{ "name": "Salon du Chocolat", "distance_km": 1.2 }]
  }
}
```

## Réponse — `HTTP 200`

| Champ | Valeur |
|---|---|
| `predicted_covers` | **55** (range 47–62) |
| `confidence` | **0.80** |
| `is_mock` | **false** *(forecast Prophet réel, modèle entraîné sur 365 j)* |
| `claude_used` | **true** *(reasoning Claude réel)* |
| `staffing_recommendation` | `servers: 4, hosts: 1, kitchen: 2` |

**Explication générée par Claude :**

> **Forecast: 55 covers — Confidence: 80%**
>
> The prediction of 55 covers is plausible given that clear weather at 18°C typically
> supports moderate-to-strong Friday dinner footfall in Paris, with comfortable
> conditions encouraging both walk-in traffic and guests extending their evening. The
> proximity of Salon du Chocolat (1.2 km) introduces an upside variable — event
> attendees seeking dinner post-visit may lift walk-in capture above baseline, though
> no historical comparable nights are available to quantify this effect with precision.
>
> **Operational note:** Given the event proximity and favourable weather, I would
> recommend preparing mise en place for up to 65–68 covers as a prudent buffer, while
> holding staffing at the level appropriate for 55 covers until reservation pace in the
> next 24–48 hours confirms or revises the trajectory.
